API Reference

Exported Types and Functions

SIFTFeatures.SIFTConfig — Type

SIFT parameters. first_octave=-1 doubles the input on a pixel-aligned grid. Contrast uses OpenCV semantics (the threshold is divided by octave_layers). Descriptors always have 4×4 spatial cells and 8 orientation bins. Set rootsift=true to return L1-normalized elementwise square-root (RootSIFT / Hellinger) descriptors, which remain unit-L2 normalized for standard Euclidean matching.

source
SIFTFeatures.SIFTKeypoint — Type

A subpixel SIFT feature. x and y are one-based column/row coordinates, sigma is the Gaussian standard deviation in original-image pixels, and angle is clockwise from +x in radians, in [0, 2π). octave is signed; layer is zero-based.

source
SIFTFeatures.DescriptorMatch — Type

One-based descriptor column indices and their Euclidean (not squared) distance.

source
SIFTFeatures.sift — Function
keypoints, descriptors = sift(img; config=SIFTConfig(), octaves=nothing)

Native SIFT detection and description. Returns floating-point keypoints and a 128×N Float32 matrix with unit-L2 columns. Multiple strong orientations create separate features. nfeatures=0 keeps all features; otherwise keep the strongest. Set SIFTConfig(rootsift=true) to compute RootSIFT (Hellinger) descriptors directly.

source
SIFTFeatures.match_descriptors — Function
match_descriptors(a, b; ratio=0.8, crosscheck=false)

Brute-force L2 matching for 128×N descriptors. Accept only a strict Lowe ratio between the nearest and second-nearest neighbors. Fewer than two train columns or tied nearest neighbors yield no match. crosscheck=true also requires a mutual nearest neighbor (it does not apply a reverse ratio test).

source
SIFTFeatures.rootsift — Function
rootsift(descriptors)

Return a RootSIFT-transformed copy of a nonnegative SIFT descriptor vector or column-wise matrix. See rootsift!.

source
SIFTFeatures.rootsift! — Function
rootsift!(descriptors)

In-place RootSIFT (Hellinger) transform for a nonnegative descriptor vector or column-wise descriptor matrix: L1-normalizes each vector/column and applies the elementwise square root (leaving all-zero vectors unchanged). The output columns have unit L2 norm so Euclidean matching computes the Hellinger kernel.

source
SIFTFeatures.gaussian_pyramid — Function

Build Gaussian octaves, each containing octave_layers + 3 Float32 matrices. Input is a one-based AbstractMatrix of normalized real values, unsigned integer pixels, or JuliaImages colors. Empty input gives an empty pyramid.

source
SIFTFeatures.dog_pyramid — Function

Adjacent Gaussian differences, with octave_layers + 2 levels per octave.

source

SIFTFeatures.grayscale_float — Function

Convert a one-based real, unsigned integer, or color matrix into a Matrix{Float32} with intensities validated to lie in [0, 1]. Unsigned pixels are divided by typemax.

source
SIFTFeatures.double_image — Function

Upsample a by 2× using pixel-aligned bilinear interpolation (x -> 2x, edge replication at the far border).

source

Return a Gaussian-blurred copy of a with standard deviation sigma. See gaussian_blur!.

source

Separable symmetric four-sigma Float32 Gaussian blur with reflect-101 borders, writing into dst.

Compute the default number of SIFT pyramid octaves for image img and configuration c.

source
SIFTFeatures.is_extremum — Function

Test whether DoG sample (y, x, l) is strictly greater or strictly less than all 26 scale-space neighbors.

source
SIFTFeatures.derivatives — Function

Compute the 3D finite-difference gradient and Hessian (g, H) (ordered x, y, scale) at DoG sample (y, x, l).

source
SIFTFeatures.localize — Function

Iteratively refine a discrete DoG extremum (y, x, l) via 3D quadratic interpolation, rejecting low-contrast and edge responses. Returns a named tuple or nothing.

source
SIFTFeatures.orientations — Function

Compute dominant keypoint orientations in radians [0, 2π) around (y, x) at octave scale sigma. See orientations!.

source

Compute dominant keypoint orientations in radians [0, 2π) (clockwise from +x) into angles using a reusable OrientationWorkspace.

source
SIFTFeatures.descriptor — Function

Compute a 128-element unit-L2 SIFT (or RootSIFT when rootsift=true) descriptor around (y, x, sigma, angle). See descriptor!.

source
SIFTFeatures.descriptor! — Function

Compute a 128-element unit-L2 SIFT (or RootSIFT when rootsift=true) descriptor into out using a reusable DescriptorWorkspace.
